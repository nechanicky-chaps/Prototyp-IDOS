# FlixBus – Android

Zápis 15. 9. 2026. Dva snímky z uživatelem znovu dodané sady (přílohy 1–2). Originály zachovány a kopie ověřeny SHA-256. Android; přihlášení a verze nezjištěny. Jiný chat nebyl načítán.

Uživatel oceňuje minimalistický design a připisuje jej menší nabídce slev a kombinací. Celkový rozsah tarifů ani příčinná souvislost nejsou ověřeny.

## Pozorování a inspirace

Cestující jsou dostupní před hledáním. Editor ukazuje pouze dospělého, dítě a kolo s počty a minus/plus, potvrzení fajfkou nahoře. Hranice dětské kategorie není v tomto stavu vysvětlena. U kola je stručné upozornění. Systémová lišta pořízení snímku dole není součástí aplikace.

Pro IDOS je inspirací jednoduchý základ a informace přímo u příslušné volby. Nelze však automaticky přenést rozsah tří položek na prostředí s více dopravci a průkazy. Ověřit následné zadání věku dítěte, limity počtu a skupinu s různými potřebami.
