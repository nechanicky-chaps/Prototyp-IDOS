# Virtuální Plzeňská karta – Android

Lokální podklady k výběru cestujících. Zachyceny jsou pouze dva přímo související stavy: otevřená tarifní kategorie osoby „Já“ a celé rozbalené počty spolucestujících pod vyhledávacím formulářem.

Uživatel řešení popsal jako zvláštní tím, že je vše umístěné pod vyhledávacím polem. Přesná verze aplikace, stav přihlášení a navazující kroky nebyly z dodaných snímků zjištěny.
