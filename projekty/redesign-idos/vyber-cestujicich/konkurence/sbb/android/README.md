# SBB Mobile – Android

Lokální podklady k výběru uložených osob a zadání nového spolucestujícího. Zachyceny jsou dva bezprostředně související spodní dialogy.

Uživatel pozitivně hodnotí designový minimalismus, ale nevyhovuje mu požadavek na zadání celého data narození. Přesná verze aplikace, stav přihlášení a navazující kroky nebyly z dodaných snímků zjištěny.
