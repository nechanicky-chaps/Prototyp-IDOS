# RegioJet – Android

Zápis 15. 9. 2026. Tři snímky z uživatelem znovu dodané sady (přílohy 3–5). Originály zachovány a kopie ověřeny SHA-256. Android; přihlášení a verze nezjištěny. Jiný chat nebyl načítán.

Uživatel oceňuje minimalistický design a vysvětluje jej menší nabídkou slev a kombinací. Skutečný celkový rozsah ani příčina designového řešení nebyly ověřeny.

## Pozorování a inspirace

Výběr je dostupný před hledáním. Základní editor nabízí šest kategorií osob s věkem, plus/minus a jedním zvoleným dospělým. Další tarify lze rozbalit: ZTP, invalidita 3. stupně a průvodce ZTP/P. U některých možností je doplňující text nebo odkaz Více informací. Součet, zobrazený limit devíti osob a Potvrdit jsou ve spodní části obou stavů. Přesné tarifní nároky a skutečný limit nebyly interaktivně ověřeny.

Pro IDOS je zvlášť podnětné rozdělení na běžné a další tarify: střídmý základ může zachovat dostupnost méně častých možností. Je třeba ověřit jejich nalezitelnost a nepředpokládat, že všechny další volby jsou pro každého uživatele méně důležité. Pevné ukotvení spodního potvrzení při posouvání ze dvou snímků samotných nelze potvrdit.

Souhrn formuláře uvádí Dospělý 18–64 let, zatímco editor nad 18 let; rozdíl popisků evidovat, tarifní hranice z nich nedovozovat.
